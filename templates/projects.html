MITOS — Campus Heat Monitor

Low-power environmental sensing unit for mapping urban heat across MIT’s campus. Built around an ESP32-C3 with custom PCBs for power management, sensing peripherals (SHT4x + VEML7700), and field deployment. The node performs multi-stage buffering (RTC → flash) to survive outages, and schedules LoRa/Wi-Fi upload windows to minimize energy usage. An e-ink display provides an accessible community interface, showing local temperature, battery status, and a QR code that links to live telemetry via a custom backend dashboard.

Role: Firmare + communications implementation

Grid-thym — FPGA Music Game

Piano-Tiles-style rhythm game implemented entirely on an FPGA. An SD-card reader streams MIDI/WAV data into audio-processing pipelines, which map notes to frequencies and drive both audio synthesis and a 10×10 visual grid. The display module renders falling tiles over HDMI using BRAM-backed line buffers, while the game logic checks keyboard hits against the bottom row in real time.

Role: Designed the node architecture and SystemVerilog modules for storage layout, SD-card I/O, and tile rendering, focusing on timing, buffering, and clean interfaces between audio, visualization, and input.

Piano Tiles — PSoC Game

Built a Piano-Tiles-style game on a PSoC 5LP using a 240×320 TFT display, interrupt-driven button input, and real-time audio synthesis through the on-chip VDAC. Notes are generated using a wavetable synthesizer that steps through a sine-wave table inside a SysTick ISR, while the game renders falling tiles via the emWin graphics library over SPI.
